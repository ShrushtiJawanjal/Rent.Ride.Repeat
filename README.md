# Rent.Ride.Repeat
Rent.Ride.Repeat is a Django marketplace bridging travelers and manager. It replaces manual booking processes with an automated, user-centric solution. The website is structured around essential functional modules, including User Registration, a dynamic Vehicle Gallery, Owner Management portals, and an interactive Booking Form. It allows for a streamlined workflow where vehicle availability is tracked in real-time, ensuring a reliable experience for both the customer and the service provider.
Tech Stack
Backend: Python 3.x, Django Framework
Frontend: HTML5, CSS3 (Modern Glassmorphism UI), JavaScript
Database: SQLite / PostgreSQL (Django ORM)
Authentication: Django Auth System for secure user/owner logins
